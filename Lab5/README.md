# Лабораторна робота №5. Варіант 12: рух тіла похилою площиною без тертя

Програма на C++ з бібліотекою SFML 3, пакетним менеджером vcpkg і системою збирання CMake. Моделює ковзання тіла по похилій площині без тертя.

## Фізична та математична модель

Сила тяжіння mg розкладається на складову, перпендикулярну до площини (її компенсує реакція опори), і складову вздовж площини mg·sin α. За другим законом Ньютона:

    a = g * sin(alpha)

Чисельне інтегрування з кроком dt:

    v(n+1) = v(n) + a * dt
    s(n+1) = s(n) + v(n+1) * dt

Теоретичний час руху на відстань L: t = (-v0 + sqrt(v0^2 + 2*a*L)) / a. Масштаб: 1 м = 100 пікселів, g = 980 пікс/с^2.

## Збирання і запуск (macOS)

    export VCPKG_ROOT=$HOME/vcpkg
    cmake --preset default
    cmake --build --preset default
    cd build
    ./SFML_Lab

Запускати потрібно з папки build, бо шлях до шрифту відносний.

## Керування

| Клавіша | Дія |
|---|---|
| Up / Down | збільшити / зменшити кут нахилу (5-40 градусів) |
| Right / Left | збільшити / зменшити початкову швидкість (0-300) |
| Space | запустити / призупинити |
| R | перезапустити |

У вікні відображаються кут, прискорення, початкова і поточна швидкість, пройдений шлях, час і статус. Жовта лінія показує траєкторію тіла.

## Результати експерименту

Вплив кута (v0 = 0, L = 525 пікс):

| Кут | a | t чисельно, с | t теорія, с | Відн. похибка |
|---|---|---|---|---|
| 10 | 170.2 | 2.48413 | 2.48397 | 0.006 % |
| 20 | 335.2 | 1.76995 | 1.76993 | 0.001 % |
| 30 | 490.0 | 1.46374 | 1.46385 | 0.008 % |
| 40 | 629.9 | 1.29098 | 1.29106 | 0.006 % |

Вплив початкової швидкості (кут 30):

| v0 | t чисельно, с | t теорія, с | Відн. похибка |
|---|---|---|---|
| 0 | 1.46374 | 1.46385 | 0.008 % |
| 100 | 1.27606 | 1.27393 | 0.167 % |
| 200 | 1.11138 | 1.11153 | 0.013 % |
| 300 | 0.974543 | 0.974482 | 0.006 % |

Висновки: прискорення зростає з кутом як sin(alpha) і не залежить від маси; час руху обернено пропорційний sqrt(sin(alpha)); початкова швидкість скорочує час руху; чисельна модель збігається з теорією (похибка до 0.17 %), розбіжність визначається кроком dt.
